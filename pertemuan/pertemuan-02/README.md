## Praktikum

Membuat aplikasi TypeScript modular dengan pemisahan model, service, dan utility.

## Tujuan

Mahasiswa mampu:
1. Menggunakan TypeScript lanjutan (union, generic, optional)
2. Membuat arsitektur modular
3. Memisahkan concerns dalam project
