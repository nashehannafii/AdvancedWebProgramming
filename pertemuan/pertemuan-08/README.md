## Bentuk Penilaian

- **Praktik**: Implementasi kode langsung

## Tugas

Bangun REST API lengkap dengan:

- **TypeScript**: Penulisan code dengan type safety
- **Bun**: Runtime environment
- **Elysia**: Web framework
- **MySQL**: Database storage

## Requirements Minimal

| Komponen | Requirements | Status |
|----------|--------------|--------|
| CRUD | Create, Read, Update, Delete | Wajib |
| REST API | Endpoint sesuai konvensi REST | Wajib |
| Database | MySQL dengan minimal 1 tabel | Wajib |
| Validation | Input validation di server | Wajib |
| Error Handling | Tangani error dengan baik | Wajib |
